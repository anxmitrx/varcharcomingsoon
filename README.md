# VARCHAM (Varcham India) — Sacred Chandan Botanica

> **The Purest Devotion. The Rarest Chandan.**  
> Sustainably harvested, museum-grade sandalwood for your most sacred rituals. The divine essence is unveiling soon.

An ultra-premium, responsive "Coming Soon" landing page crafted with React 19, Vite, Tailwind CSS v4, and Framer Motion.
Corporate Sanctum: BL-B, P 1/2, Bangur Avenue, LP-89/8, Kolkata – 700055, West Bengal (Near JK Masala, Bangur).

---

## ✨ Features

- **Spiritual Luxury Aesthetic**: Warm ivory / rich off-white canvas (`#FDFBF7`) with antique brass & sandalwood brown accents.
- **Divine Ambience & Puja Motifs**: Sacred yantra and lotus mandala background silhouettes, paired with still-life editorial photography of an aged Mysore sandalwood heartwood log on an antique copper plate with a brass *dhoop dani* incense burner.
- **Continuous Drifting Dhoop Smoke**: Fluid, hardware-accelerated CSS keyframe animations simulating translucent incense smoke drifting into the atmosphere.
- **Flawless Responsiveness**: Centered flexbox layout with mobile-first responsiveness and high contrast typography (*Playfair Display*, *Cinzel*, and *Plus Jakarta Sans*).

---

## 🛠️ Tech Stack

- **Framework**: [React 19](https://react.dev/) + [Vite 8](https://vite.dev/)
- **Styling**: [Tailwind CSS v4](https://tailwindcss.com/)
- **Animations**: [Framer Motion](https://www.framer.com/motion/)
- **Icons**: [Lucide React](https://lucide.dev/)
- **Language**: TypeScript

## 🚀 Getting Started

### 1. Install Dependencies
```bash
npm install
```

### 2. Start Local Development Server
```bash
npm run dev
```
Open [http://localhost:5173](http://localhost:5173) in your browser.

### 3. Production Build
```bash
npm run build
```
Preview the built artifacts:
```bash
npm run preview
```
